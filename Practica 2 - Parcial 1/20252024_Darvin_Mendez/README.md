# Práctica 1er Parcial - Calculadora Matemática en Java

Este proyecto consiste en una aplicación de consola que simula una calculadora básica, desarrollada para la asignatura de **Programación 1**.

## 🚀 Funcionalidades
El programa permite realizar las siguientes operaciones matemáticas:
* **Suma**
* **Resta**
* **Multiplicación**
* **División** (Incluye validación para evitar la división por cero)

## 🛠️ Tecnologías y Conceptos Aplicados
Para cumplir con los requisitos de la práctica, se implementaron:
* **Encapsulamiento:** Atributos de clase privados.
* **Estructuras de Control:** Menú interactivo con `switch` y bucle `do-while`.
* **Manejo de Excepciones:** Uso de `try-catch` para validar que las entradas sean números.
* **Documentación:** Código comentado bajo el estándar **JavaDoc**.

## 📖 Instrucciones de Uso
1. Descarga el archivo `CalculadoraMatematica.java`.
2. Ábrelo en tu IDE (NetBeans, IntelliJ o Eclipse).
3. Ejecuta el programa y selecciona una opción del menú.
