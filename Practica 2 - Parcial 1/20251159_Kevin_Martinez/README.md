## Ejecución del Programa

**opción 1**
1. Abrir el proyecto en NetBeans.
2. Seleccionar el proyecto completo
3. Presionar click derecho
4. Seleccionar "Run file"
5. Seguir las instrucciones mostradas en el menú.

**opción 2**
1. Abrir la terminal
2. Dirigirse a la ruta donde se encuentra el archivo
3. Escribir el siguiente comando "java CalculadoraMatematica"
4. Seguir las instrucciones mostradas en el menú.
