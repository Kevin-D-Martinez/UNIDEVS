# Tarea 4.1: Interfaz Gráfica de Usuario (GUI) en Java

Este proyecto consiste en una aplicación de escritorio desarrollada en **Java** utilizando el entorno de desarrollo **NetBeans**. El objetivo principal es la implementación de una interfaz gráfica (Swing) para la captura y visualización de datos de participantes, aplicando principios de Programación Orientada a Objetos (POO).

## 🚀 Características

- **Encapsulamiento:** Uso de atributos privados y métodos públicos para el manejo de datos.
- **Separación de Responsabilidades:** La lógica de procesamiento está desacoplada de la interfaz gráfica a través de la clase `ProcesarDatos`.
- **Interfaz Intuitiva:** Diseño limpio con etiquetas, campos de texto y botones de acción.
- **Mensajería Dinámica:** Uso de `JOptionPane` para confirmar acciones y mostrar resultados.
