# Tarea 4.1 - GUI

## Descripción
Este proyecto consiste en el desarrollo de una interfaz gráfica en Java utilizando NetBeans, que permite capturar y presentar los datos de un participante.

Se aplican los principios de encapsulamiento y separación de responsabilidades mediante una clase llamada `ProcesarDatos`, encargada de almacenar y procesar la información.

## Funcionalidad
- Captura datos del participante (matrícula, nombres, apellidos, cuatrimestre)
- Almacena los datos en la clase `ProcesarDatos`
- Muestra los datos mediante una ventana emergente

- Swing (JFrame, JButton, JTextField)
