# 📊 Sistema de Registro Académico (Java Swing)

Este proyecto es una aplicación de escritorio desarrollada en **Java** utilizando la librería **Swing**. Permite capturar datos personales de un estudiante y calcular su nota final basada en cuatro criterios de evaluación.

## 📝 Descripción

El sistema valida que las calificaciones ingresadas estén dentro de los rangos permitidos y determina automáticamente si el estudiante ha **APROBADO** o **REPROBADO** la asignatura.

### Estructura de Calificación:

- **Prácticas:** Máximo 40 pts.
- **Parciales:** Máximo 20 pts.
- **Asignaciones:** Máximo 20 pts.
- **Examen Final:** Máximo 20 pts.
- **Condición de aprobación:** Nota total ≥ 60 puntos.

## 🚀 Requisitos e Instalación

1. Tener instalado el **JDK** (Java Development Kit) versión 8 o superior.
2. Clonar este repositorio o descargar el archivo `CalculadoraNotas.java`.
3. Compilar y ejecutar desde tu IDE favorito (NetBeans, IntelliJ, VS Code) o desde la terminal:

```bash
javac CalculadoraNotas.java
java CalculadoraNotas
```
