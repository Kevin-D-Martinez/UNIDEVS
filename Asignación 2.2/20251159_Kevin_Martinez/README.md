El programa consiste en una calculadora que puede hacer operaciones matemáticas básicas.

Esta contiene sobrecarga en los métodos "sumar, restar y multiplicar", 
siendo estos con parámetros entre dos a cuatro por métodos.

---

## Estructura del Proyecto

El proyecto está compuesto por una clase:

### `Claculadora`
clase que contiene los métodos que hacen las operaciones matemáticas

**Métodos principales:**
- `sumar(int a, int b)`
- `restar(int a, int b)`
- `multiplicar(int a, int b)`
- `dividir(int a, int b)`

---

## Ejecución del Programa

**opción 1**
1. Abrir el proyecto en NetBeans.
2. Crear un archivo .java.
3. Crear una clase "Main".
4. Crear un metodo estatico main para usar los metodos de la clase.
5. Crear una instancia de la clase "Calculadora".
6. Llamar los metodos a usar.
7. Seleccionar las líneas de código del archivo completo
8. Presionar click derecho
9. Seleccionar "Run file"

**opción 2**
1. Crear un archivo .java
2. Crear una clase "Main" para usar los metodos de la clase
3. Crear un metodo estatico main para usar los metodos de la clase.
4. Crear una instancia de la clase "Calculadora".
5. Llamar los metodos a usar.
6. Guardar las líneas de código
7. Abrir la terminal
8. Dirigirse a la ruta donde se encuentra el archivo
9. Complilar los archivos con "javac Calculadora.java Main.java"
10. Correr el archivo donde esta el main con "java Calculadora"
