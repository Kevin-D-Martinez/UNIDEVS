# Calculadora Avanzada y Conversor de Temperatura

Proyecto desarrollado en Java Swing que integra operaciones matemáticas básicas, avanzadas y conversión de unidades térmicas en una sola interfaz.

## Características

- **Aritmética:** Suma, Resta, Multiplicación y División.
- **Validación:** Control de división por cero mediante bloques IF y excepciones.
- **Avanzado:** Cálculo de Raíz Cuadrada y Exponentes (Potencia).
- **Conversor:** Transformación bidireccional entre Celsius y Fahrenheit.

## Estructura de Clases (POO)

- `Calculadora.java`: Lógica de operaciones básicas.
- `ConversorTemperatura.java`: Lógica de conversión de unidades.
- `Raizcuadrada_Exponente.java`: Lógica de funciones matemáticas especiales.
- `Main.java`: Interfaz gráfica y control de eventos.

## Ejecución

Compilar y ejecutar el archivo Main:

```bash
javac src/*.java
java src/Main
```
