# Calculadora Extendida - Proyecto Java Swing

## Descripción
Este proyecto es una calculadora extendida desarrollada en Java Swing que permite realizar operaciones básicas, conversión de temperatura, raíz cuadrada y potencia.

## Funcionalidades
- Suma
- Resta
- Multiplicación
- División
- Validación de división por cero
- Conversión de temperatura (Celsius a Fahrenheit y Fahrenheit a Celsius)
- Raíz cuadrada
- Potencia (exponente)
- Historial de operaciones
- Botón para limpiar campos y borrar historial

## Cómo ejecutar
1. Abrir el proyecto en NetBeans.
2. Ejecutar la clase CalculadoraGUI.java.
3. Ingresar los valores en los campos.
4. Presionar el botón de la operación deseada.
