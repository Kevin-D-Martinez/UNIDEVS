El programa consiste en una creación de 3 instancias de tipo "Tv".
Esta se le agregan valores a sus atributos mediante línea de código

---

## Estructura del Proyecto

El proyecto está compuesto por dos clases:

### `Tv`
clase que contiene los atributos y métodos de la aplicación

**Atributos:**
- `public String marca`
- `public int pulgadas`
- `public int volumen`

**Métodos principales:**
- `encender()`
- `apagar()`
- `subirVolumen()`
- `bajarVolumen()`

---

### `Prueba`
clase que donde se ejecuta el programa

## Ejecución del Programa

**opción 1**
1. Abrir el archivo en NetBeans.
2. Seleccionar la líneas de código del archivo "prueba" completo.
3. Presionar click derecho.
4. Seleccionar "Run file".

**opción 2**
1. Abrir la terminal.
2. Dirigirse a la ruta donde se encuentra los archivos.
3. Escribir el siguiente comando "javac Tv.java Prueba.java".
4. Correr el archivo con el main usando "java Prueba".
