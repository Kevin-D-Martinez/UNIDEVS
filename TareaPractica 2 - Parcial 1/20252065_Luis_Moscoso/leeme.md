# 🧮 Calculadora Matemática en Java

## 📌 Descripción

Este proyecto consiste en el desarrollo de una **calculadora matemática básica** utilizando el lenguaje de programación **Java** y aplicando los principios fundamentales de la **Programación Orientada a Objetos (POO)**.

El programa permite al usuario ingresar dos números y realizar diferentes operaciones matemáticas mediante un menú interactivo en consola.

---

## 🎯 Objetivos del Proyecto

- Aplicar conceptos de Programación Orientada a Objetos.
- Utilizar atributos privados y métodos públicos.
- Implementar estructuras de control (`switch` y `do-while`).
- Manejar entrada de datos con la clase `Scanner`.
- Validar errores matemáticos como la división por cero.
- Documentar código utilizando **JavaDoc**.

---

## ⚙️ Funcionalidades

El sistema permite realizar las siguientes operaciones:

✅ Ingresar números  
✅ Suma  
✅ Resta  
✅ Multiplicación  
✅ División (con validación de división por cero)  
✅ Menú interactivo repetitivo hasta seleccionar salir
