Esta es un programa que hace calculos de matemática básicos.

---

## Ejecución del Programa

**opción 1**
1. Abrir el archivo en NetBeans.
2. Seleccionar las líneas de código del archivo completo.
3. Presionar click derecho.
4. Seleccionar "Run file".
5. Seguir las instrucciones mostradas en el menú.

**opción 2**
1. Abrir la terminal.
2. Dirigirse a la ruta donde se encuentra el archivo.
3. Complilar el archivo con "javac CalculadoraMatematica.java".
4. Correr el archivo donde esta el main con "java CalculadoraMatematica".
5. Seguir las instrucciones mostradas en el menú.
